## 💼 LinkedIn Draft

I'm thrilled to share our hackathon project for the **TigerGraph × Hacker House Goa 2026 Agentic Fraud Investigation Hackathon**! 🛡️

Detecting financial fraud requires more than examining isolated transaction attributes. Real fraud operates as connected networks: shared device profiles, regional mobility patterns, and multi-card syndicates.

Our solution, **TigerGraph Fraud Sentinel**, combines graph database analytics with autonomous agentic reasoning:

Key Highlights:
1. **Graph-Native Analysis**: Leveraging TigerGraph Savanna and GSQL, our agent computes historical baselines, device fan-out, and regional travel signatures without overloading the LLM with raw tabular rows.
2. **Model Context Protocol (MCP)**: Implements the official TigerGraph MCP standard (`tigergraph-mcp`) for seamless tool discovery and query execution.
3. **GraphRAG Case Memory**: Hybrid retrieval combining structured graph entity traversals with semantic vector similarity across 5,565 closed cases and regulatory guidance.
4. **Autonomous Policy Engine**: A deterministic guardrail enforcing the bank's Fraud Policy (Rules R1-R10), action execution priorities, and approval routing (`auto`, `L1 Team Lead`, `L2 Fraud Manager`).
5. **Interactive Governance Console**: A Streamlit interface providing step-by-step agent timelines, interactive PyVis network graph visualizations, and human-in-the-loop approval workflows.

All 20 benchmark exam cases were executed in chronological order and passed rigorous rubric validation checks with 100% precision.
